# Imagens das apresentações

## capa-wagasa.jpg
Foto de capa do roteiro do Japão (`index.html`). Guarda-sóis de papel
oleado (wagasa) pintados à mão.

Basta salvar o arquivo com este nome exato nesta pasta — a capa passa a
usá-lo automaticamente, sem alterar o HTML. Se o arquivo não existir, a
capa cai no fundo em degradê e não quebra.

Recomendado: JPEG, largura mínima de 2000 px, abaixo de 600 KB.
