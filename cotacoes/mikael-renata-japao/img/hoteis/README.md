# Fotos dos hotéis
A página `index.html` procura 6 fotos por hotel nesta pasta, com os nomes exatos abaixo (JPEG, proporção 4:3 recomendada, até 400 KB cada). Enquanto o arquivo não existir, o espaço mostra o nome do hotel e o número da foto; ao salvar o arquivo com o nome certo, a foto entra sozinha, sem mexer no HTML.
A capa usa `../capa.jpg` (pasta `img/`).
